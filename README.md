# هجولة — Hajwala

## فكرة المستودع
لعبة قيادة وسباقات ودرفت بواجهة عربية تعمل من المتصفح، مطورة انطلاقًا من Kenney Starter Kit Racing، مع تجارب واقع معزز.

## الخدمات والمزايا
- قيادة باللمس أو لوحة المفاتيح، وخصوم آليون وتوقيت للفات.
- تخصيص لون السيارة والنص والعلم، مع إضاءة وأصوات قيادة.
- محرر لإنشاء الحلبات ومشاركتها.
- وضع واقع معزز للنظارات المتوافقة، ووضع مدينة ليلي تجريبي بالمطر والنيون.
